# デュエマ買取価格トラッカー

カードラッシュのデュエマ買取表（全カード／只今の買取額UP!!）を毎日1回記録し、
100〜30,000円のカードのうち **値段が動いたものだけ** をグラフで見られるページを作ります。

- 毎日 日本時間7:40ごろに自動実行（GitHub側の混雑で数十分遅れることがあります）
- 初日は基準の記録だけ。**2日目から**変動が表示されます
- 一度記録したカードは、30,000円を超えたり100円を下回ったりしても追い続けます

## はじめての設定（PCで約20〜30分）

1. **GitHubアカウントを作る**
   https://github.com を開き「Sign up」からメールアドレスで登録します。

2. **保管場所（リポジトリ）を作る**
   右上の「＋」→「New repository」を選びます。
   - Repository name: `dm-price-tracker`
   - **Public** を選びます（無料で結果ページを公開するために必要です）
   - そのほかは何も変えずに「Create repository」を押します

3. **ファイルをアップロードする**
   - このzipを展開し、`dm-price-tracker` フォルダを開きます
   - リポジトリのページにある「uploading an existing file」をクリックします
   - フォルダの中身（`.github`、`docs`、`scraper.py`、`requirements.txt`、`README.md`）を
     **すべて選択してページにドラッグ**します
   - 下の「Commit changes」を押します
   - **確認：** 一覧に `.github` が表示されていればOKです。表示されていなければ、
     「Add file」→「Create new file」でファイル名に `.github/workflows/daily.yml` と入力し、
     zip内の同名ファイルの中身を貼り付けて「Commit changes」を押してください

4. **書き込みを許可する**
   「Settings」→ 左側の「Actions」→「General」→ 下の方の「Workflow permissions」で
   **Read and write permissions** を選び「Save」を押します。

5. **1回目を手動で動かす**
   上部の「Actions」タブを開きます（有効化を求められたら緑のボタンを押します）。
   左の「毎日の買取価格記録」→ 右の「Run workflow」→ 緑の「Run workflow」を押します。
   5〜10分ほどで緑のチェックが付けば成功です。

6. **結果ページを公開する**
   「Settings」→ 左側の「Pages」→「Build and deployment」で
   - Source: **Deploy from a branch**
   - Branch: **main** と **/docs** を選んで「Save」
   1〜2分後、同じ画面の上部に `https://（ユーザー名）.github.io/dm-price-tracker/` が表示されます。
   これをスマホでブックマークしてください。

## うまくいかないとき

- Actionsの実行に赤い ✕ が付いたら、その実行を開き、赤くなっている手順の画面をスクリーンショットして
  Claudeに送ってください。カードを読み取れなかった場合は、実行ページ下部の「Artifacts」に
  `debug` という調査用ファイルが残るので、それも渡すと直しやすくなります。
- 60日間リポジトリに変化がないと自動実行が止まることがあります。その場合はActionsタブで
  再度有効化してください（毎日記録が保存されていれば通常は止まりません）。

## ページの見方

- **前回比／7日／30日／90日／全期間**：どの時点と比べるか
- **上昇／下落**：絞り込み
- **買取強化中のみ**：今「只今の買取額UP!!」に載っているカードだけ
- カードをタップすると推移グラフが開きます（🔥＝その日は強化中）
- 「掲載なし」は最新の買取表に載っていなかったカードです

## 変えたいとき

- 価格帯：`scraper.py` の `MIN_PRICE` / `MAX_PRICE`
- 実行時刻：`.github/workflows/daily.yml` の `cron`（UTCで指定。日本時間−9時間）

サイトに負担をかけないよう、1日1回・ページごとに2秒待って取得しています。
